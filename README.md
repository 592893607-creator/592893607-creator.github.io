# 个人作品集网站

这是静态网站，GitHub Pages 提供免费公开地址；Pages CMS 提供网页登录编辑。作品与图片保存在 GitHub 仓库里，保存内容会产生 Git 提交，并触发 GitHub Actions 自动发布。

## 首次发布

1. 在 GitHub 新建一个名为 **你的 GitHub 用户名.github.io** 的 **Public** 仓库。这个仓库名会让网站部署在 `https://你的用户名.github.io/` 根路径，使上传图片的路径直接可用。公开作品集对应的源码和示例内容也会公开；确认不要放私密素材、私人证件或未获授权的作品文件。
2. 将本目录中的所有文件（包括 `.pages.yml` 和 `.github`）上传到仓库根目录，分支使用 `main`。
3. 打开仓库的 **Settings → Pages**，将构建来源设为 **GitHub Actions**。
4. 打开 **Actions**，启用工作流；第一次部署完成后，GitHub 会显示网站地址。项目站点通常是 `https://你的用户名.github.io/仓库名/`。
5. 打开 [Pages CMS](https://app.pagescms.org/)，使用自己的 GitHub 账号登录，将 Pages CMS GitHub App 安装到该仓库，然后进入“网站资料”或“作品集”编辑。

## 以后怎么编辑

在 Pages CMS 修改作品标题、分类、说明、年份、封面图和视频链接。点击保存会更新 GitHub 仓库；Actions 部署完成后，公开网站会自动更新。封面图可直接上传。视频建议继续用公开视频平台或网盘的公开播放链接，不要把大视频文件直接提交到 GitHub。

页面目前采用固定的手机适配布局，不提供任意拖拽排版；CMS 面板管理作品内容与顺序。中英双语尚未启用，当前网站为中文。

## 访问与费用说明

GitHub Pages 和 Pages CMS 可从免费方案开始，不需要购买域名或备案。GitHub Pages 位于境外，国内网络下的可用性和图片加载速度可能不稳定；无备案条件时，这个方案优先满足零托管费，不能承诺国内稳定访问。后续如果需要国内稳定访问，需评估大陆托管和备案要求。

## 自定义资料

- `content/site.json`：CMS 管理的姓名、自我介绍、职业方向与联系信息。
- `content/works.json`：CMS 管理的作品数据。
- `.pages.yml`：CMS 编辑字段及图片上传路径。
- `index.html`：页面文案、联系信息和视觉样式。发布前替换姓名、邮箱、微信占位内容；替换示例作品，确认照片与视频有公开展示授权。
